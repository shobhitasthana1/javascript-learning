# OOP Lessons

This folder contains object-oriented programming practice examples in JavaScript.

## Folder Structure

```text
01-object-basics/
  object-literal/
02-classes-and-objects/
  biscuit-maker/
  book-print/
  bottle/
  class-expression/
03-prototypes/
  prototype-methods/
04-this-keyword/
  this-contexts/
05-call-apply-bind/
  call-method/
  apply-method/
  bind-method/
06-inheritance/
  basic-inheritance/
07-getters-and-setters/
```

## Lesson Order

1. `01-object-basics/object-literal` - Object literal example
2. `02-classes-and-objects/biscuit-maker` - Class, constructor, and method example
3. `02-classes-and-objects/book-print` - Class example with multiple objects
4. `02-classes-and-objects/bottle` - Class example with object methods
5. `02-classes-and-objects/class-expression` - Class expression example
6. `03-prototypes/prototype-methods` - Prototype methods example
7. `04-this-keyword/this-contexts` - `this` keyword behavior examples
8. `05-call-apply-bind/call-method` - `call()` method example
9. `05-call-apply-bind/apply-method` - `apply()` method example
10. `05-call-apply-bind/bind-method` - `bind()` method example
11. `06-inheritance/basic-inheritance` - Basic inheritance example
12. `07-getters-and-setters` - Getter and setter example

## How To Run

Open the `index.html` file inside any lesson folder in your browser.
